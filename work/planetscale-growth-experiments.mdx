## Setup

Analytics was already in place. What was missing was a way to test against it, so
I set up GrowthBook — and then spent most of the work on trusting it, verifying
the data and checking measurement accuracy before anything got called a result.

The site was static, and staying fast was the point. That ruled out the usual
client-side variant swap: it costs a flash of the original and a second render
behind it. Experiments run through a proxy and a rewrite instead, so a visitor is
served the variant already rendered — no flicker, no client-side branch, and the
pages keep their static performance.
