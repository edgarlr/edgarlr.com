PlanetScale is a hosted database platform. The brand team had designed a new
homepage, animated from top to bottom, and I was brought in to build it as the
only engineer.

The main decision was to build the motion on native web APIs wherever possible,
so the page stays light and every animation has a reduced-motion path. The
diagram is the clearest case: it builds as you scroll, made from sticky elements
and intersection observers instead of scroll-jacking. The hero's pixel grid is a
lazy-loaded canvas, swapped for a static grid on low-powered devices, and the
carousel runs on native scroll snap.
