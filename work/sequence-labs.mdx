Sequence Labs is where Sequence shares what it is experimenting with in AI and
agents: what the team is learning, and projects that may never ship. It sits
apart from the main site on purpose. Labs is an exploratory playground, so it
had to read as bold and experimental, clearly set apart from the main product.

I was given the project brief, then worked on it end to end: branding design,
page structure, web design and build.

That feeling lives mostly in the shaders, and the brand is built around them,
alongside the particles and parallax, with a Konami code hidden inside. The
control strip on the landing page is live, so visitors can tune the shader
themselves; internally I developed a few set of tools for fine-tuning each element.
