## What it is

A starter for digital magazines: Next.js and Strapi, with IndexedDB on the
client. It ships tuned for performance and already wired to the CMS, so the work
left over is publishing rather than plumbing.

It began as a personal project for a friend who needed one, and is open source
because the next person needing one shouldn't have to start over.
